# 교육다함 (Edu-Da-Ham) v41

기존 교육ON v40 기반. 교육 등록/수정에서 필수교육 체크박스(기본 미선택)를 추가했습니다. `isMandatory` 불리언 속성으로 기존 교육 데이터에 호환되며, 연간 교육일정의 교육명 앞에 빨간색 작은 윗첨자 ‘필수’를 표시합니다. 기존 교육구분과는 독립적으로 동작합니다. 시스템 표시명을 교육다함 (Edu-Da-Ham)으로 변경했습니다.

배포 시 ZIP의 모든 파일(index.html, api/, vercel.json, legacy/)을 함께 업로드하세요.


## v42 수정
- 교육 등록·수정 팝업 최상단에 필수교육 여부 표시(기본 미체크, 기존 데이터 유지).
- 교육근거 입력칸 높이 축소, 행 간격과 텍스트박스 높이 조정.
- 데스크톱에서 팝업의 두 열을 독립적으로 스크롤하도록 하고 저장 버튼이 초기 화면에 보이도록 최적화. 작은 화면에서는 스크롤 허용.


v43: 등록/수정 팝업의 필수 교육 체크박스를 왼쪽 정렬하고 레이블을 간결화. 공문 추출 내용 제목·내용 복사 버튼·안내 문구 및 하단 설명 문구를 숨기거나 삭제. 원본 미리보기 기능은 유지.


## v44 변경
- 교육 등록/수정 화면의 수강과목·교육기관 및 교육대상·이수요건 입력칸 높이를 각각 2배로 확대 (일반 화면 62→124px, 낮은 화면 48→96px).


v46: 현황 조회 버튼 스타일 통일, 전체교육 이수현황 제목, 개별 교육 이수현황 제목, 고정 열 너비 조정.


v47: 전체교육 이수현황의 0/X 표시 font-weight normal(400), 0 녹색, X 빨간색.


## v49 변경
- 서무 전용 상단 부서원 관리 메뉴 추가.
- 직원 등록/수정을 입력 팝업으로 변경. 부서·팀·직급·직위·행정번호·담당업무·재직상태 관리.
- 전출·퇴직 시 직원 비활성화 및 개인 링크 무효화, 기존 교육 수료이력 보존.
- 주의: 현재 관리자 키는 전체 DB에 접근합니다. 부서별 권한 분리와 서버 검증은 별도 구현 필요.


v50: 부서원 관리 엑셀형 인라인 편집, 행 추가, 전출·복직, 변경사항 일괄 저장.


## v51 변경
- 부서원 관리의 행 관리 열 제거, 인사이동 입력 열 추가, 서무주사 복수 체크박스 추가.
- 인사이동 시 기존 직원 ID와 수료이력을 유지하며, 이동 부서의 전체 대상 교육에 배정.
- 동일 행정번호 중복 검증, 엑셀 명단 재가져오기 시 동일 행정번호 병합.
- **주의**: v51은 기존 전역 관리자 접근키 기반이며, 부서별 서무의 독립적인 서버 권한 인증은 아직 구현되지 않았습니다. 여러 부서의 실제 운영에 앞서 서버 권한 분리 및 DB 분할이 필요합니다.
