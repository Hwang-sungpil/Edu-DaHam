# 교육다함 (Edu-Da-Ham) v41

기존 교육ON v40 기반. 교육 등록/수정에서 필수교육 체크박스(기본 미선택)를 추가했습니다. `isMandatory` 불리언 속성으로 기존 교육 데이터에 호환되며, 연간 교육일정의 교육명 앞에 빨간색 작은 윗첨자 ‘필수’를 표시합니다. 기존 교육구분과는 독립적으로 동작합니다. 시스템 표시명을 교육다함 (Edu-Da-Ham)으로 변경했습니다.

배포 시 ZIP의 모든 파일(index.html, api/, vercel.json, legacy/)을 함께 업로드하세요.


## v42 수정
- 교육 등록·수정 팝업 최상단에 필수교육 여부 표시(기본 미체크, 기존 데이터 유지).
- 교육근거 입력칸 높이 축소, 행 간격과 텍스트박스 높이 조정.
- 데스크톱에서 팝업의 두 열을 독립적으로 스크롤하도록 하고 저장 버튼이 초기 화면에 보이도록 최적화. 작은 화면에서는 스크롤 허용.


v43: 등록/수정 팝업의 필수 교육 체크박스를 왼쪽 정렬하고 레이블을 간결화. 공문 추출 내용 제목·내용 복사 버튼·안내 문구 및 하단 설명 문구를 숨기거나 삭제. 원본 미리보기 기능은 유지.
