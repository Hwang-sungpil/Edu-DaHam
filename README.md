# 교육다함 v63 — GitHub / Vercel 배포

## 배포
이 폴더의 `index.html`, `api/`, `vercel.json`을 GitHub 저장소 **최상위**에 업로드하세요. Vercel 프로젝트의 Git 저장소/브랜치가 일치하는지 확인하고 새 배포를 진행합니다.

기존 Vercel 환경변수 `NOTION_TOKEN`, `NOTION_DATABASE_ID`, `ADMIN_ACCESS_TOKEN`을 유지하세요. 가능하면 별도 `SESSION_SECRET`(길고 무작위인 비밀값)을 추가하세요. **기존 ADMIN_ACCESS_TOKEN은 삭제하지 마세요**(환경 설정 및 서명 키 대체용).

## 로그인
공통 주소에서 **행정번호-개인암호4자리**를 한 칸에 입력합니다. 최초 암호는 모든 사용자 `1111`. 전체관리자는 `0000-1111`이며 환경설정에서 관리자 번호 및 개인암호를 변경할 수 있습니다. 서무주사/부서원은 등록된 행정번호를 사용합니다.

환경설정에서 본인 암호를 변경할 수 있습니다. 서무주사는 같은 부서 직원의 암호를 1111로 초기화할 수 있고, 전체관리자는 서무주사 암호를 초기화할 수 있습니다. 한 부서에 서무주사를 여러 명 지정할 수 있습니다. 실제 암호는 관리 화면에 표시하지 않습니다.

## 주의
- 4글자 암호는 공개 인터넷 운영에 충분한 인증 보안이 아닙니다. 실제 사용 전 시도 제한, 추가 인증 및 암호 정책 강화가 필요합니다.
- Notion의 기존 교육·직원 데이터는 유지합니다. 서버에 저장된 기존 링크 토큰은 로그인에 사용하지 않습니다.
- 직원 행정번호는 전체 부서에서 고유해야 합니다. 관리자 번호와도 중복되면 안 됩니다.
- 기존 공문 PDF 원본은 브라우저 로컬 저장 특성상 다른 PC에서 재첨부가 필요할 수 있습니다.
- 실제 Notion/Vercel 배포 및 연동 검증은 이 패키지에서 수행되지 않았습니다.
