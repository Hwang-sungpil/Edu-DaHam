# 교육다함 v68

GitHub 최상위에 모든 파일을 업로드합니다. `api/`, `legacy/`, `assets/`, `vercel.json` 포함.

신규 기능: 교육대상 제외 자동 판별, 유사 교육 중복 경고 및 예외 등록, 교육실적 진단, 선택형 Gemini AI 공문 분석/개선 제안.

**AI 기능 상세 안내:** [AI_기능_설명서.md](AI_기능_설명서.md)

## v69
- 교육 등록/수정 화면에서 직원 선택 목록 및 AI/재판별 버튼 숨김. 공문 첨부 시 자동 판별.
- 제외 조건 미확인 시 부서원 전체 기본 지정. 제외 직원만 강조 표시.
- 유사 교육 저장 시 전용 확인창: 등록하지 않고 종료 / 신규 등록.
- 기존 api, legacy, assets 및 vercel.json 유지.

## v70 — 동일 교육 중복 확인 오류 수정
- 교육명 동일 여부를 유사도 계산보다 먼저 판정합니다. 공백·괄호·문장부호·유니코드 표기 차이도 정규화합니다.
- `교육 저장` 클릭 시 Vercel API에서 **최신 교육 목록을 다시 조회**하여 다른 브라우저/PC에서 등록된 교육도 비교합니다.
- 동일·유사 교육이 있으면 기존 교육명·이수기한을 보여주고 `등록하지 않고 종료` 또는 `신규 등록`을 선택합니다.
- 수정 화면에서는 현재 수정 중인 교육(id)은 중복으로 판단하지 않습니다.
- 서버 목록 조회에 실패하면 중복을 놓친 채 저장하지 않도록 저장을 중단하고 안내합니다.
- 기존 교육/부서원/이수 기록 및 API·legacy 구조는 변경하지 않았습니다.
