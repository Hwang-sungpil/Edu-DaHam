# 교육다함 (edu-da-ham)

**교육공문 등록부터 직원별 교육 이수 관리, 교육실적 분석까지 한곳에서 처리하는 부서 교육관리 웹 서비스**

## 1. 접속 주소 및 실행 환경

- **서비스 접속:** https://edu-daham.vercel.app/
- **실행 방법:** 인터넷이 연결된 PC에서 웹브라우저로 위 주소에 접속합니다.
- **운영체제:** 특정 OS에 종속되지 않는 웹 서비스입니다. 
- **브라우저:** Microsoft Edge 또는 Google Chrome 권장. 
- **설치:** 이용자 PC에 별도 프로그램을 설치할 필요가 없습니다.
- **권장 사양:** 최신 웹브라우저를 실행할 수 있는 일반 사무용 PC 및 안정적인 인터넷 연결.

> 본 프로젝트는 별도 `.exe` 실행파일을 제공하는 설치형 프로그램이 아닙니다. **실행 가능한 웹 애플리케이션의 원본 파일(`index.html`, `api/`, `assets/` 등)과 배포 설정(`vercel.json`)을 프로젝트에 함께 포함**했습니다. `index.html`만 로컬에서 여는 방식은 서버 API와 데이터 저장 기능을 완전하게 실행하는 방법이 아닙니다.

## 2. 주요 기능

| 사용자별 | 주요 기능 |
| --- | --- |
| 전체관리자 | 기관 부서 등록·관리, 부서별 서무주사 등록, 서무주사 로그인정보 관리 |
| 서무주사 | 부서원 명단 등록(엑셀·CSV 가져오기 또는 직접 입력), 직원 로그인정보 관리, 교육공문 첨부·정보 추출 및 교육 등록, 교육대상 확인, 동일·유사 교육 등록 경고, 연간 교육일정·전체교육 이수현황 조회, 직원별 수료 처리, 교육실적 분석 |
| 일반 부서원 | 본인에게 배정된 교육 조회, 교육 수료 여부 등록, 개인암호 변경 |

교육분석 화면에서는 교육별·월별·직급별·팀별 현황과 교육실적 진단을 확인할 수 있습니다. 

## 3. 실행·작동 방법 (처음 이용하는 경우)

1. **사이트 접속:** 웹브라우저에서 https://edu-daham.vercel.app/ 에 접속합니다.
2. **전체관리자 로그인:** 로그인 입력란에 `행정번호-개인암호` 형식으로 입력합니다.
     초기 전체관리자 계정의 행정번호는 `0000`, 초기 개인암호는 `1111`입니다. 이미 변경한 경우에는 변경된 정보를 사용합니다.
     *부서 및 서무주사 등록:* 전체관리자 화면의 *시스템 관리*에서 상위 조직(국)·실과명을 등록하고, 해당 부서의 서무주사 정보(부서·팀명·성명·행정번호·직급)를 입력합니다.
5. **서무주사 로그인정보 전달:** 전체관리자가 **서무주사 로그인정보**에서 등록된 행정번호를 확인하여 담당자에게 전달합니다. 개인암호를 잊은 경우에는 초기화 기능을 이용합니다.
6. **서무주사 로그인 및 부서원 등록:** 서무주사가 전달받은 정보로 로그인한 뒤 **부서원 관리 → 엑셀·CSV 명단 가져오기**에서 부서원 명단을 등록하거나 직접 입력합니다.
7. **교육 등록:** 서무주사가 **교육정보 관리 → + 교육 등록**에서 교육공문을 첨부하고 자동 추출된 교육명·이수기한 등 항목과 대상자를 확인·수정한 후 저장합니다. 동일·유사 교육 경고가 나타나면 기존 교육 여부를 확인합니다.
8. **부서원 로그인정보 안내:** 서무주사가 **환경설정 → 직원 로그인정보 관리**에서 직원의 행정번호를 확인하고 필요 시 암호를 초기화하여 로그인 방법을 안내합니다. 기존 개인암호를 조회하는 기능은 아닙니다.
9. **부서원 수료 등록:** 일반 부서원이 같은 주소로 로그인한 후 **나의 교육현황**에서 본인 교육의 수료 여부를 등록합니다. **환경설정 → 개인암호 변경**에서 암호를 변경할 수 있습니다.
10. **서무주사 이수현황 확인:** 서무주사가 **연간 교육일정**에서 교육명을 선택하여 직원별 수료 상태를 확인하거나 **전체교육 현황조회**에서 교육별 이수현황을 확인합니다. 필요한 경우 직원별 수료일을 지정하고 수료 처리할 수 있습니다.
11. **교육실적 분석:** 서무주사가 **교육분석**에서 교육별·월별·직급별·팀별 현황과 교육실적 진단을 확인합니다. Gemini가 연결되어 있다면 **Gemini AI 개선 제안 생성**을 실행할 수 있습니다.

## 4. 시연용 데이터

- **부서원 명단:** `기획예산실.xlsx` — 교육대상자 확인 및 직원별 이수현황 시연용. **부서원 관리 → 엑셀·CSV 명단 가져오기**에서 등록합니다. 이미 등록된 명단이 있다면 다시 업로드하지 않고 조회할 수 있습니다.
- **교육공문:** PDF·HWPX·DOCX·TXT 파일 — **교육정보 관리 → + 교육 등록**에서 첨부해 정보 추출 및 등록 과정을 시연합니다.

`나주시-기획예산실.xlsx`는 시연에 사용하기로 한 파일명이며, 이 저장소에 해당 원본 파일이 포함되어 있는지는 별도로 확인해야 합니다. 실제 직원 정보가 포함된 파일은 공개 저장소에 올리지 마세요.

## 5. AI(LLM) 연결 및 모델 변경

- **기본 모델:** Google Gemini 2.5 Flash (`gemini-2.5-flash`)
- **연결 파일:** `api/ai.js` (Vercel 서버리스 API)
- **API 키:** Vercel 프로젝트 **Settings → Environment Variables**에서 `GEMINI_API_KEY` 등록
- **모델 변경:** 같은 설정 화면에서 `GEMINI_MODEL`에 사용할 Gemini 모델 ID를 입력한 뒤 재배포합니다. 설정하지 않으면 기본 모델이 적용됩니다.
- **시연 경로:** 서무주사 로그인 → **교육분석 → Gemini AI 개선 제안 생성**

교육공문 첨부 시 기본 정보 추출과 대상자 판별은 문서 텍스트 처리 및 규칙 기반 기능입니다. 공문 업로드 자체가 Gemini를 자동 호출한다고 설명하지 않습니다. 다른 AI 사업자의 모델로 전환하려면 `api/ai.js`의 API 연동 방식 수정이 필요합니다.

```text

```

## 7. 확인된 제약 및 주의사항

- 스캔 이미지 중심의 공문은 OCR 기능이 없어 자동 텍스트 추출이 제한될 수 있습니다.
- 공문 자동 추출·교육대상 판별·중복 교육 판단 결과는 등록 전에 서무주사가 확인해야 합니다.
- 교육공문 원본 첨부파일은 등록 브라우저의 저장소에 보관되는 방식이므로 다른 이용자에게 원본 파일이 자동 공유되는 것은 아닙니다. 등록된 교육정보와 별도로 입력된 공문 원문 URL은 구분됩니다.
- Gemini 기능은 API 키와 외부 서비스 연결이 필요하며, 호출 실패 시 AI 제안 생성이 제한됩니다.
- 데이터 저장은 Notion DB에 의존하며, 현재 코드에는 저장 데이터 크기에 대한 제한이 있습니다.
- 현재 로그인 방식은 짧은 개인암호를 사용하므로 실제 기관 단위 확대 운영 시 인증·보안 정책을 검토해야 합니다.
